# Package Tracking App

A personal package tracking application designed to automatically organize online orders and deliveries from multiple retailers and carriers.

## Problem

Managing multiple online orders can become difficult when purchases are made from different retailers and delivered by different carriers. Tracking information is often spread across emails, retailer websites, and carrier websites, making it difficult to remember what was purchased and when each package is expected to arrive.

## Goal

The goal of this project is to create an application that automatically identifies order and shipping information from a user's connected email account and organizes active and delivered packages in one place.

The application will prioritize automation and minimize manual data entry whenever possible.
